## About me

I build **developer tools, self-hosted infrastructure, and product software**.

My background spans frontend, backend, and product engineering, with a long stretch in the TypeScript ecosystem. These days, I mostly reach for **Rust** and use **AI as a core part of my engineering workflow** — from exploration and implementation to review and iteration.

I like small, explicit systems built from boring, well-understood primitives.

## Currently building

### Tancho

An **AI-native application development environment (ADE)**.

My current main project, exploring how development environments and AI agents can work together as a coherent engineering workflow rather than as isolated coding assistants.

### [Kilnr](https://github.com/godart-corentin/kilnr)

A small self-hosted CI system built around standard Linux primitives.

**Rust · Git · systemd · Docker · GNU Make**

Exact-SHA builds, isolated jobs, pipelines, artifacts, secrets, caching, releases, and a CLI/web interface — without requiring a full CI platform.

### [Yard](https://github.com/godart-corentin/yard)

A deliberately boring deployment tool for self-hosted Docker Compose applications.

**Rust · Docker Compose · Git · Linux**

Predictable deploy, rollback, backup, health-check, and release-management workflows for single-server infrastructure and homelabs.

## Selected work

### [Devjournal](https://github.com/godart-corentin/devjournal)

A local-first developer journal that turns Git activity into useful daily and standup summaries.

**Rust · SQLite · Git · LLMs**

Built around keeping development history local while supporting OpenAI, Anthropic, Ollama, and structured non-LLM workflows.

### [Dotfiles](https://github.com/godart-corentin/dotfiles)

My reproducible Linux desktop setup for **CachyOS + Hyprland**, with an idempotent installer and configuration for Walker, Noctalia, and Elephant.

**Linux · CachyOS · Hyprland · Shell**
